# API Testing Framework Demo

Легкий и быстрый фреймворк для API-тестирования на Python с использованием pytest.

## 🎯 Описание проекта

Этот проект демонстрирует современный подход к автоматизации API-тестирования (Middle+ AQA). Фреймворк включает:

- **Базовый API-клиент** с поддержкой сессий, заголовков и обработкой ошибок
- **Структурированные тесты** с использованием pytest
- **Валидацию ответов** через JSON Schema и Pydantic models
- **Логирование** всех запросов и ответов
- **Генерацию тест-данных** с помощью Faker
- **Allure отчеты** для визуализации результатов
- **CI/CD интеграцию** для автоматического запуска тестов

## ✨ Особенности и улучшения

### 🔧 API Клиент
- **Логирование**: Детальное логирование всех запросов и ответов (метод, URL, параметры, время ответа)
- **Retry механизм**: Автоматические повторы при ошибках (5xx, таймауты) с настраиваемым количеством попыток
- **Кастомные исключения**: Информативная обработка ошибок (`APIRequestException`, `APITimeoutException`, etc.)
- **Типизация**: Полная типизация с type hints для лучшей поддержки IDE

### ✅ Валидация
- **JSON Schema**: Валидация структуры ответов API
- **Pydantic модели**: Типобезопасная валидация данных (`UserModel`, `CreateUserRequest`, etc.)
- **Валидация производительности**: Проверка времени ответа API

### 🧪 Тесты
- **Улучшенные тесты**: Allure steps, валидация, проверка производительности
- **Тесты производительности**: Проверка времени ответа различных эндпоинтов
- **Тесты безопасности**: Проверка авторизации, защита от SQL инъекций
- **Параметризация**: Гибкая параметризация для негативных тестов

### 🏗️ Структура проекта
- **Модуль config/**: Управление окружениями (dev/staging/prod) через переменные окружения
- **Модуль utils/**: Переиспользуемые утилиты (валидаторы, генераторы данных, хелперы)
- **conftest.py**: Централизованные фикстуры pytest для переиспользования кода

### 📊 Отчетность
- **Allure интеграция**: Детальные отчеты с steps, attachments, группировкой по маркерам
- **HTML отчеты**: Альтернативный формат отчетов pytest

### 🔄 CI/CD
- **GitHub Actions**: Автоматический запуск тестов на нескольких версиях Python
- **Линтинг**: Автоматическая проверка кода с ruff
- **Артефакты**: Сохранение отчетов для анализа

### 🎯 Генерация данных
- **Faker интеграция**: Генерация реалистичных тестовых данных
- **UserDataGenerator**: Удобный класс для генерации пользователей и тест-данных

## 📈 Преимущества для уровня Middle+ AQA

- **Профессиональная структура**: Модульная архитектура, разделение ответственности
- **Надежность**: Retry механизм, обработка ошибок, валидация данных
- **Поддерживаемость**: Документация, типизация, логирование
- **Масштабируемость**: Легко добавлять новые тесты, гибкая конфигурация
- **Качество кода**: Линтинг, типизация, best practices

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd pytest-api-demo
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
```

3. Активируйте виртуальное окружение:
```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

## 🏃 Запуск тестов

### Базовый запуск всех тестов:
```bash
pytest
```

### Запуск с маркерами:
```bash
# Только smoke тесты
pytest -m smoke

# Пропустить slow тесты
pytest -m "not slow"
```

### Запуск с Allure отчетом:
```bash
# Запуск с генерацией Allure результатов
pytest --alluredir=allure-results

# Открыть отчет в браузере
allure serve allure-results
```

### Параллельный запуск:
```bash
pytest -n auto
```

### Запуск с логированием:
```bash
pytest -v -s
```

## 🧪 Примеры тестов

### Простой тест:
```python
def test_get_user(api_client):
    response = api_client.get("/users/1")
    assert response.status_code == 200
    assert response.json()["id"] == 1
```

### Тест с валидацией схемы:
```python
def test_create_user_success(auth_client):
    payload = {"email": "test@example.com", "role": "user"}
    response = auth_client.post("/users", json=payload)
    
    assert response.status_code == 201
    validate_json_schema(response.json(), user_schema)
```
