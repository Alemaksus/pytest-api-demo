### 2. 🏗️ Структура проекта

#### Модуль config/
- **Что добавлено**: `config/settings.py` - управление настройками

### 3. 🔧 Улучшения API клиента

#### Логирование
- **Что добавлено**: Детальное логирование всех запросов и ответов
- **Зачем**: Упрощает отладку и анализ проблем
- **Что логируется**:
  - Метод и URL запроса
  - Параметры и тело запроса
  - Статус код и время ответа
  - Тело ответа

#### Retry механизм
- **Что добавлено**: Автоматические повторы при ошибках
- **Зачем**: Устойчивость к временным сбоям сети/сервера
- **Настройки**:
  - Количество попыток (по умолчанию 3)
  - Задержка между попытками
  - Retry только для определенных ошибок (5xx, таймауты)

#### Кастомные исключения
- **Что добавлено**: `client/exceptions.py`
- **Зачем**: Более информативная обработка ошибок
- **Исключения**:
  - `APIException` - базовое
  - `APIRequestException` - ошибки HTTP запросов
  - `APITimeoutException` - таймауты
  - `APIValidationException` - ошибки валидации
  - `APIRetryException` - исчерпаны попытки retry

## 🚀 Как использовать

1. **Установка**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка**:
   - Создайте `.env` файл (см. README.md)
   - Настройте `BASE_URL` и другие параметры

3. **Запуск тестов**:
   ```bash
   pytest -v                    # Все тесты
   pytest -m smoke              # Только smoke
   pytest --alluredir=allure-results  # С Allure
   ```

4. **Просмотр отчетов**:
   ```bash
   allure serve allure-results
   ```
